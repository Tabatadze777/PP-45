## 1. ფუნქცია როგორც ობიექტი

### ამოცანა 1.1 - ფუნქციების ლექსიკონი
შექმენით ლექსიკონი, სადაც გასაღებებია `"add"` (მიმატება), `"sub"` (გამოკლება), `"mul"` (გამრავლება), `"div"` (გაყოფა), მნიშვნელობები კი შესაბამისი ფუნქციები. მომხმარებლისგან აიღეთ ორი რიცხვი და ოპერაციის სახელი, შემდეგ ლექსიკონიდან აირჩიეთ ფუნქცია და დაბეჭდეთ შედეგი.

---

## 2. დეკორატორები

### ამოცანა 2.1 - მისალმება
დაწერეთ დეკორატორი `greet`, რომელიც ფუნქციის გამოძახებამდე ბეჭდავს `"Starting..."`-ს, გამოძახების შემდეგ კი `"Done!"`-ს. დეკორატორმა უნდა იმუშაოს ნებისმიერი რაოდენობის არგუმენტზე (`*args`, `**kwargs`) და უნდა დააბრუნოს ორიგინალი ფუნქციის შედეგი.

### ამოცანა 2.2 - დროის გაზომვა
დაწერეთ დეკორატორი `timer`, რომელიც ზომავს ფუნქციის შესრულების დროს (`time` მოდულით) და ბეჭდავს: `"<ფუნქციის სახელი> executed in 0.0123 seconds"`. გამოიყენეთ `@wraps`. გამოსაცდელად დაწერეთ ფუნქცია, რომელიც დიდ ციკლს ასრულებს.

---

## 3. დეკორატორი პარამეტრით

### ამოცანა 3.1 - მინიმალური ასაკი
დაწერეთ დეკორატორი `min_age(limit)`, რომელიც ამოწმებს ფუნქციის პირველ არგუმენტს (`age`). თუ ის `limit`-ზე ნაკლებია, ფუნქცია არ სრულდება და იბეჭდება `"Access denied"`.

```python
@min_age(18)
def enter_club(age):
    print("Welcome!")

enter_club(20)  # Welcome!
enter_club(15)  # Access denied
```

### ამოცანა 3.2 - ხელახლა ცდა
დაწერეთ დეკორატორი `retry(times)`, რომელიც ფუნქციას ხელახლა გამოიძახებს, თუ ის შეცდომას (`Exception`) გამოიწვევს, მაქსიმუმ `times`-ჯერ. თუ ყველა ცდა წარუმატებელია, დაბეჭდეთ `"All attempts failed"`.

გამოსაცდელად გამოიყენეთ ფუნქცია, რომელიც `random`-ის გამოყენებით ხან ვარდება, ხან არა (ნულზე გაყოფისას Python თავისით იწვევს `ZeroDivisionError`-ს):

```python
import random

@retry(5)
def random_division():
    number = random.randint(0, 3)  # 25%-იანი შანსით მივიღებთ 0-ს
    print(f"Dividing 10 by {number}")
    result = 10 / number
    print(f"Result: {result}")

random_division()
```

მაგალითი შედეგისა (შემთხვევითობის გამო ყოველ გაშვებაზე განსხვავებულია):

```
Dividing 10 by 0
Dividing 10 by 0
Dividing 10 by 2
Result: 5.0
```
